# 찬양팀 예배 스케줄

정적 HTML로 만든 찬양팀 예배 스케줄 관리 프로그램입니다.

## 주요 기능

- 예배 일정 등록, 편집, 삭제
- 팀원 등록, 편집, 삭제
- 팀원별 정기 참여 요일과 월간 가능/불가능 날짜 관리
- 주간 일정, 월간 일정, 통계 화면
- 홈 화면의 다음 예배 정보와 오늘의 말씀

## 배포

별도 빌드 과정 없이 GitHub 저장소를 Vercel에 연결해 배포할 수 있습니다.

- 루트 접속: `worship-schedule.html`로 이동
- Vercel 설정: `vercel.json`
- 말씀 목록: `bible.md`
